# ABEL QUEST

An 8-bit RPG-themed portfolio for **Abel Sirak Kebede** — The Code Warrior.

## Features

- Retro game boot screen and HUD
- Character stats, skill tree, quest board, and trophy room sections
- Framer Motion animations and custom pixel cursor
- Fully responsive layout

## Tech Stack

- React 18 + Vite
- Tailwind CSS
- Framer Motion
- React Icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |

## Project Structure

```
src/
```
